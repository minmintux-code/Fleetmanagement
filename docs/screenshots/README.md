# Fleet Manager - System Screenshots Gallery

This directory contains screenshot placeholders and visual assets for the **Fleet Manager** web application.

---

## Screen Modules Overview

| Screen Module | Path / Placement | Description |
| :--- | :--- | :--- |
| **Login Screen** | `login.png` | 256-bit TLS corporate login portal |
| **Dashboard Command Center** | `dashboard.png` | Real-time metric cards (Vehicles, Drivers, Trips, Fuel, Revenue, Expenses in ₹) and analytics charts |
| **Vehicle Management** | `vehicles.png` | Fleet vehicle registry, status badges, and mileage tracking |
| **Driver Management** | `drivers.png` | CDL commercial driver roster, safety index ratings, and license expiry alerts |
| **Trip Dispatch Module** | `trips.png` | Dispatch itinerary planning, route distance (KM), and status tracking |
| **Customer & Rental Contracts**| `rentals.png` | Corporate customer agreements, daily rates in INR (₹), and contract dates |
| **Fuel Refill Logs** | `fuel.png` | Refill logs, volume in liters, cost per liter in INR (₹), and station tracking |
| **Maintenance Work Orders** | `maintenance.png` | Preventive & emergency repair work orders, service centers, and costs in INR (₹) |
| **Reports & Analytics** | `reports.png` | Operating expenditure bar charts and vehicle composition doughnut charts |
| **System Settings** | `settings.tsx` | Organization details, alert windows, and INR (₹) currency configuration |

---

> [!NOTE]
> To capture screenshots of the running application:
> 1. Launch backend (`./mvnw spring-boot:run`) and frontend (`npm run dev`).
> 2. Open `http://localhost:5173`.
> 3. Save module screenshots into `docs/screenshots/` using the filenames listed above.
